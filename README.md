# Портфолио системного аналитика

Коллекция учебных, хакатонных и pet-проектов по системному анализу. Здесь собраны артефакты работы с требованиями, моделями данных и процессов, пользовательскими сценариями, интеграциями и API.

## Проекты

| Проект | Формат | Домен | Основные артефакты |
| --- | --- | --- | --- |
| [Career Tracker](pet-projects/carrier-tracker/README.md) | Pet-проект | Карьерный трекинг | UJM, Use Case, UML Sequence, SiteMap, OpenAPI |
| [Pay2U](hackathones/hackathon_pay2u/README.md) | Хакатон | Финтех | Use Case, логическая модель данных, UML Sequence, OpenAPI |
| [CRM для амбассадоров](hackathones/hackathon_CRM_ambass/README.md) | Хакатон | CRM | Use Case, системная UML Sequence, модель данных, руководство пользователя |
| [Yandex Event / FunTech](hackathones/hackathon_funtech/README.md) | Хакатон | Событийный сервис | Use Case, ERD, UML Sequence, OpenAPI |
| [Яндекс Практикум](YP_education_projects/README.md) | Обучение | Системный анализ | требования, DFD, ER-модели, API, дипломный проект |

## Навигация

```text
SA/
├── YP_education_projects/  # учебные работы Яндекс Практикума
├── hackathones/            # хакатонные кейсы
├── pet-projects/           # самостоятельные проекты
└── templates/              # шаблоны для оформления новых проектов
```

## Что представлено

- сбор и формализация требований;
- моделирование пользовательских и системных сценариев: Use Case, UJM, UML Sequence;
- проектирование данных и процессов: ERD, DFD и логические модели;
- описание ролей, интерфейсов и навигации;
- подготовка OpenAPI/Swagger-спецификаций и требований к API.

## Лицензия и конфиденциальность

Артефакты опубликованы для демонстрации профессионального опыта. Конфиденциальные данные, токены, реальные персональные данные и внутреннюю информацию заказчиков в репозиторий не добавляются.
