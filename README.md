# SA Projects

Репозиторий с проектами и артефактами по системному анализу.

Здесь собраны учебные работы, хакатонные кейсы и pet-проекты, связанные с проектированием информационных систем, описанием требований, моделированием процессов, API-спецификациями и подготовкой аналитической документации.

## Содержание

```text
SA/
├── YP_education_projects/     # Учебные проекты Яндекс Практикума
│   ├── basic/                 # Базовый уровень
│   └── middle/                # Middle-уровень, ДЗ и дипломный проект
│
├── hackathones/               # Хакатонные проекты
│   ├── hackathon_CRM_ambass/
│   ├── hackathon_funtech/
│   └── hackathon_pay2u/
│
├── pet-projects/              # Личные проекты
│   └── carrier-tracker/
│
└── .gitignore
Участвовал в 4 хакатонах по системному анализу. В портфолио представлены артефакты анализа и проектирования информационных систем: Use Case, UML Sequence Diagram, ERD, BPMN/процессные модели, UJM, SiteMap, описание ролей и пользовательских сценариев, OpenAPI/Swagger-спецификации, требования к API и интеграциям.

Ключевые кейсы:
— Career Tracker — pet-проект карьерного трекера: описание пользовательских сценариев, ролей, интерфейсов, UJM, Use Case, UML Sequence Diagrams и OpenAPI-спецификация для пользовательских досок, вакансий, откликов, уведомлений, справочников и метрик прогресса.
— Pay2U — хакатонный финтех-кейс: Use Case, логическая модель данных, UML Sequence Diagram и Swagger/OpenAPI-спецификация API.
— CRM для амбассадоров Практикума — хакатонный CRM-кейс: Use Case, системная UML Sequence Diagram, модель данных и пользовательская документация.
— Yandex/Event/Funtech-кейс — хакатонный/учебный проект: Use Case, UML Sequence Diagram, ERD и OpenAPI-спецификация.
— В YP_education_projects указаны учебные проекты с 2 двух обучений яндекса
